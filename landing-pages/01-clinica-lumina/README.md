# Clínica Lumina

Landing page responsiva criada como entrega do `Nível 1` da trilha Front-End da Sistemium.

## Objetivo

Praticar a base real do front-end antes de entrar em framework, usando:

- HTML semântico;
- CSS com layout responsivo;
- formulário simples;
- JavaScript básico para validação;
- organização em arquivos separados.

## Requisitos atendidos

- cabeçalho;
- seção principal;
- seção de benefícios;
- formulário de contato;
- rodapé;
- responsividade para celular e desktop;
- validação simples com JavaScript.

## Estrutura

- `index.html`: estrutura da página.
- `style.css`: visual, layout, responsividade e estados visuais.
- `script.js`: validação simples do formulário.
- `docs/ROTEIRO-DE-TESTE-MANUAL.md`: roteiro manual de validação.
- `docs/NIVEL-1-REQUISITOS-E-CHECKLIST.md`: checklist da entrega.

## Como abrir

Abra o arquivo `index.html` no navegador.

## Como testar

1. Abrir `index.html` no navegador.
2. Validar a leitura da página em desktop.
3. Reduzir a largura da janela para validar a adaptação para celular.
4. Testar o formulário vazio e com dados inválidos.
5. Testar o formulário com dados válidos e confirmar a mensagem de sucesso.

## Evidências da entrega

- landing page funcional em HTML, CSS e JavaScript;
- validação simples com JavaScript;
- documentação da entrega;
- log de estudos atualizado em `log-de-estudos/2026-07-14-nivel-1.md`.

## Observação de escopo

Este projeto foi mantido propositalmente simples para refletir a etapa do `Nível 1`, sem consumo de API, sem framework e sem TypeScript.
