## O que o Nível 1 pede em `INS-008`

Landing page responsiva com:

- cabeçalho;
- seção principal;
- seção de benefícios;
- formulário de contato;
- rodapé;
- responsividade para celular e desktop;
- validação simples com JavaScript;
- README explicando como rodar.

## Como esta entrega atende ao escopo

Projeto analisado:

- `landing-pages/01-clinica-lumina`

O projeto possui:

- HTML semântico com seções organizadas;
- layout com grid e flexbox;
- responsividade com media queries;
- formulário com campos reais;
- validação simples em JavaScript;
- README com instruções de abertura e teste.
