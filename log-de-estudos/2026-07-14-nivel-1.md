# Log de estudos - Nível 1 - 14/07/2026

## O que fiz hoje

Desenvolvi a entrega atual do `Nível 1` da trilha Front-End com uma landing page responsiva em HTML, CSS e JavaScript.

## O que pratiquei

- HTML semântico;
- organização de seções de página;
- CSS com variáveis, grid, flexbox e responsividade;
- formulário simples;
- validação de campos com JavaScript;
- leitura do escopo do `INS-008` para não avançar para framework;
- documentação da entrega com README, checklist e roteiro de teste.

## O que entrou na entrega

- cabeçalho;
- seção principal;
- seção de benefícios;
- formulário de contato;
- rodapé;
- layout responsivo para celular e desktop;
- validação simples em JavaScript.

## O que aprendi

Aprendi que o `Nível 1` do front-end já exige mais do que abrir arquivos simples. A interface precisa ter estrutura clara, leitura boa, adaptação entre telas e comportamento mínimo de formulário.

Também ficou mais claro para mim como HTML, CSS e JavaScript se conectam quando a página deixa de ser só exercício isolado e passa a virar uma interface completa, mesmo ainda sem framework.

## Evidências geradas

- landing page em `landing-pages/01-clinica-lumina/`;
- README da entrega com instruções de uso;
- checklist de requisitos do Nível 1;
- roteiro de teste manual;
- atualização do README principal e do plano de progressão.

## Próximo passo

Após a revisão desta entrega, o próximo avanço natural é estudar o `Nível 2`, entrando em JavaScript moderno, consumo de API, loading, error state, armazenamento local e organização em módulos.
